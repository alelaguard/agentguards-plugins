# Licensing

This repository holds code under two licences. Each plugin folder's `LICENSE` file is
the one that applies to that folder.

| Folder | Licence |
|---|---|
| `claude/`, `codex/`, `gemini/`, `copilot/`, `opencode/` (hosted plugins) | [Functional Source License 1.1, MIT Future License](https://fsl.software) (`FSL-1.1-MIT`), see each folder's `LICENSE` |
| `claude-selfhosted/`, `codex-selfhosted/`, `gemini-selfhosted/`, `copilot-selfhosted/` (self-hosted appliance plugins) | MIT, see each folder's `LICENSE` or the root [`LICENSE`](./LICENSE) |
| Everything else (`cli/`, `tests/`, CI) | MIT, see the root [`LICENSE`](./LICENSE) |

## What FSL means for you

You can read, use, modify and redistribute the hosted plugins for any purpose **except a
Competing Use**: offering them, or something substantially similar built from them, in a
commercial product or service that competes with AgentGuards. Using them with your own
AgentGuards account, inside your company, for education or for research is all permitted.

Each version converts to the MIT licence **two years after its release**.
